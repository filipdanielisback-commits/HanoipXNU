# HanoipXNU XNU patches

Only HanoipXNU-authored changes belong here. Do not copy HakiOS patches or unrelated third-party patches.

Each patch series must include:
- upstream repository, tag, and base commit;
- a short purpose and affected XNU subsystems;
- source references and hardware evidence for platform changes;
- license/provenance notes for every included hunk;
- reproducible apply and reverse checks;
- build/test evidence and known limitations.

Keep patches small and ordered. Do not modify upstream source silently or claim an XNU build until it has been run against the pinned source.
