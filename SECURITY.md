# Security Policy

HanoipXNU is an experimental research project. It is not production software and must not be treated as safe for daily use.

## Reporting a concern
Please do not publish credentials, private device identifiers, personal information, signing material, or exploit details in a public issue. Use GitHub's private vulnerability reporting feature if it is enabled for this repository. Otherwise, contact the repository maintainer privately through a verified channel.

## Sensitive material
Never commit:
- Passwords, access tokens, private keys, or signing certificates
- Personal data or unique device identifiers
- Proprietary firmware, private SDKs, or restricted binaries
- Unreviewed binary images intended to be flashed to a device

## Device safety
No image in this repository should be considered safe to flash unless it has a documented build provenance, compatibility assessment, test evidence, and recovery procedure. At the current pre-alpha stage, no flashable device image is provided or endorsed.
