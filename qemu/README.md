# QEMU research environment

This directory is reserved for emulator configurations and repeatable host-side kernel experiments.

QEMU support must be treated as a separate platform from the Moto G60. A successful QEMU boot would validate only the emulated machine configuration, not phone hardware support.

The first useful target is a minimal, documented ARM64 virtual platform once the selected XNU source and required build dependencies are known. No HanoipXNU QEMU kernel currently boots.
