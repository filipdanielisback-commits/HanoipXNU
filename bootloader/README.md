# Bootloader Research

This directory is reserved for boot-chain research and future, carefully reviewed experiments.

The proposed name `xnuloader` is conceptual. No loader is implemented here. No EFI compatibility or Moto G60 boot support is claimed.

Start with the documented boot process in [docs/boot-process.md](../docs/boot-process.md). Do not create or flash device images until feasibility, compatibility, and recovery have been independently reviewed.
