# System image research

This directory is reserved for future image-layout documentation and safe, local build metadata.

Do not commit proprietary Apple operating-system files, firmware, keys, certificates, signing assets, or personal device data. Do not implement decryption or security-bypass workflows. Any future image tooling must be limited to material the user is authorized to access and must have a separate legal/provenance review.

No iOS 18 system image is included or built by HanoipXNU.
